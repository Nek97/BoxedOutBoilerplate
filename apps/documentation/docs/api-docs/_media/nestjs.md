# NestJS

Nest (NestJS) is a framework for building efficient, scalable Node.js server-side applications. Is built with and fully supports TypeScript (yet still enables developers to code in pure JavaScript) and combines elements of OOP (Object Oriented Programming), FP (Functional Programming), and FRP (Functional Reactive Programming).

Please refer to the [NestJS Documentation](https://docs.nestjs.com/) to learn about it
